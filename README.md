# AI-Powered Competitor URL to Amazon ASIN Mapping

Independent portfolio project exploring a human-supervised AI workflow for product matching.

The workflow compares critical product attributes, records evidence and reason codes, and flags uncertain cases for human review.

**Evaluation:** 12 cases across five EU marketplaces; AI decisions agreed with human judgments in 11 cases. This is a small proof of concept, not production accuracy.

This project is independent and is not an Amazon-built or endorsed system.
